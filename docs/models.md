# Модели и обучение

**Русский** · [English](models.en.md)

## Признаки и классификаторы

В каждом основном сравнении исследованы 75 конфигураций — 25 наборов признаков в сочетании с тремя классификаторами. Параметры основной матрицы фиксированы. Для выбора рабочего порога используется валидационная выборка, а ROC-AUC рассчитывается на отложенной тестовой выборке. Во всех прогонах основной матрицы начальное значение генератора случайных чисел равно 42.

| Семейство признаков | Обозначения в конфигурациях |
| --- | --- |
| Цветовые | `col1–3` |
| Частотные | `freq1–5` |
| Градиентные | `grad1–4` |
| Текстурные | `tex1–6` |
| Шумовые и признаки сжатия | `noise1–3`, `ela` |
| Комбинированные | `ml6_hybrid`, `ml7_freq_lbp`, `rob1_fusion` |

| Классификатор | Основные параметры |
| --- | --- |
| Логистическая регрессия | Стандартизация признаков, L2-регуляризация, C = 1, алгоритм L-BFGS, до 2000 итераций, балансировка классов |
| Случайный лес | 300 деревьев, глубина без ограничения, минимум два объекта в листе, число признаков для разбиения равно квадратному корню из их общего числа, балансировка классов |
| XGBoost | 300 деревьев, глубина до 6, скорость обучения 0,05, доли объектов и признаков 0,8, гистограммный метод построения деревьев |

Размеры изображений и преобразования заданы в [конфигурациях признаков](../configs/pipeline/). Параметры классификаторов можно проверить по [конфигурациям моделей](../configs/model/) и [реализации](../deepfakes/models/classical.py).

## Нейросетевые эксперименты

В [таблице нейросетевых моделей](../results/neural-baselines.csv) приведены 14 полных сравнений. Названия моделей, идентификаторы весов и размеры тестовых выборок сверены с кластерными записями. Для FFHQ / StyleGAN использованы 6000 тестовых изображений, для DeepFakeFace — 5967. Предварительная проверка ResNet-50 на 300 изображениях в таблицу не входит.

| Модель и идентификатор весов | Обучение | Проведённые сравнения |
| --- | --- | --- |
| CLIP ViT-L/14, `vit_large_patch14_clip_224.openai` | Веса кодировщика фиксированы. Центральный фрагмент 224 × 224, нормализация по параметрам весов, 64 изображения в пакете. На признаках обучались логистическая регрессия и XGBoost | Оба классификатора на обеих тестовых выборках и в контроле обработки. С логистической регрессией также оценивались устойчивость и перенос между генераторами |
| DINOv2 ViT-B/14, `vit_base_patch14_dinov2.lvd142m` | Веса кодировщика фиксированы. Центральный фрагмент 224 × 224, интерполяция позиционных представлений, нормализация по параметрам весов, 64 изображения в пакете | Логистическая регрессия и XGBoost на обеих выборках и в контроле обработки. С логистической регрессией также оценивался перенос между генераторами |
| ResNet-50, `resnet50.tv_in1k` | Дообучение всей сети на фрагментах 224 × 224. Оптимизатор Adam, скорость обучения 0,0001, 64 изображения в пакете, до 15 эпох. Ранняя остановка после трёх эпох без улучшения | На обеих выборках сопоставлены обычное обучение и обучение с размытием и сжатием JPEG |
| ViT-Tiny, `vit_tiny_patch16_224` | Признаки замороженной сети объединены с частотными признаками, локальными бинарными шаблонами и откликами фильтров Габора. После снижения размерности до 128 компонент методом PCA обучался XGBoost | На FFHQ / StyleGAN изменение размера с нормализацией ImageNet дало ROC-AUC 0,8979. Центральный фрагмент с нормализацией по параметрам весов дал 0,9164 |

Для построения парных данных использовались три режима Stable Diffusion 1.5 — реконструкция вариационным автокодировщиком, преобразование всего изображения и дорисовка области лица. Отдельный вариант StyleGAN использует готовые синтезированные изображения из «140k Real and Fake Faces». В DeepFakeFace также представлены изображения с заменой лица методом InsightFace.

## Запуск экспериментов

После [подготовки данных](datasets.md) можно запустить основную матрицу целиком или обучить отдельную модель. Для нейросетей нужны дополнительные зависимости `dl` и соответствующие предварительно обученные веса.

```sh
python -m scripts.run_benchmark data=gan_only cv=holdout seed=42
python -m pip install -e '.[dl]'
python -m scripts.run_pipeline data=dm_only pipeline=clip_l14_lp model=logreg seed=42
python -m scripts.run_pipeline data=dm_only pipeline=dinov2_b14_lp model=xgboost seed=42
python -m scripts.train_cnn data=gan_only cv=holdout +cnn.aug=blur_jpeg seed=42
python -m scripts.run_pipeline data=gan_only pipeline=rob_deep_fusion_fixed model=xgboost seed=42
```

На кластере использовались Python 3.12.4, NumPy 1.26.4, scikit-learn 1.9.1, OpenCV 5.0.0.93, XGBoost 3.4.1 и PyTorch 2.4.0 с CUDA 12.4. [Снимок окружения](../requirements-cluster.lock.txt).
